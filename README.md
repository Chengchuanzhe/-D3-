### 一、归档原则

1. 所有个人/小组成果按第1-3周严格分层存放。
2. 每周均保留：代码文件、截图证据、个人日志、协同测试记录。
3. 各成员代码保留溯源注释区间，便于检查“谁在何周完成了什么”。
